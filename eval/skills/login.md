로그인 절차입니다. 한 스텝에 행동 하나씩 실행하세요.

1. 화면의 [type] 입력창을 보세요. [type,비밀번호]로 표시된 칸이 비밀번호이고,
   나머지 [type] 칸이 아이디입니다. 아이디 칸의 라벨은 앱마다 다릅니다
   ("이메일 또는 전화번호", "카카오계정" 등) — 라벨과 무관하게 비밀번호가
   아닌 입력창이 아이디 칸입니다.
2. `fill <아이디 칸 node> username` — 금고의 아이디가 그 칸에 들어갑니다.
   값은 폰 안에서 처리되므로 당신은 값을 볼 수 없고, 볼 필요도 없습니다.
3. `fill <비밀번호 칸 node> password`
4. 두 칸을 다 채웠으면 로그인 버튼을 `tap` 하세요.
   "비밀번호 찾기", "회원가입", "간편 로그인"은 로그인 버튼이 아닙니다.
   로그인 버튼이 어느 것인지 확실하지 않으면 누르지 말고 done 하세요.
5. 누른 뒤에는 `wait` 하며 결과를 기다리세요.
   - 로그인 화면이 사라지고 다른 화면이 뜨면 성공입니다. done 하세요.
   - 로그인 화면이 그대로면 값이 틀렸거나 추가 인증이 필요한 것입니다.
     값을 다시 채우지 마세요(반복하면 계정이 잠깁니다). done으로 상황을 보고하세요.
