---
name: login
when: 아이디와 비밀번호를 입력하는 로그인 화면
needs: username, password
---
**클라우드 모델**: 이 화면에 도착했으면 직접 채우지 말고 `need username password`
를 내세요. 값은 당신에게 오지 않습니다. 기기 안 모델이 이어받아 입력합니다.

**기기 안 모델**: 아래 "넣을 값"을 받았을 것입니다. 순서대로 하세요.

1. 아이디 칸을 찾습니다. [type]으로 표시된 칸 중 [type,비밀번호]가 아닌 것입니다.
   라벨은 앱마다 다릅니다("이메일 또는 전화번호", "카카오계정") — 라벨과 무관하게
   비밀번호가 아닌 입력창이 아이디 칸입니다.
2. `tap <아이디 칸 node>`
3. `type <아이디 칸 node> <아이디 값>`
4. `tap <비밀번호 칸 node>`
5. `type <비밀번호 칸 node> <비밀번호 값>`
6. 로그인 버튼을 `tap` 합니다. "비밀번호 찾기", "회원가입", "간편 로그인"은
   로그인 버튼이 아닙니다. 어느 것인지 확실하지 않으면 누르지 말고 done 하세요.
7. `wait` 하며 결과를 기다립니다. 로그인 화면이 사라지면 성공이니 done.
   그대로면 값이 틀렸거나 추가 인증이 필요한 것입니다. 다시 채우지 말고
   (반복하면 계정이 잠깁니다) done으로 상황을 알리세요.
